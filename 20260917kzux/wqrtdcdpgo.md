**癌症不是“绝症”，可以主动干预******

许多人一听到“癌症”就慌了神，甚至直接放弃治疗——这其实是认知误区！世界卫生组织早就给出了“三个三分之一”的关键结论：

- 
三分之一的癌症完全可以预防

- 
三分之一的癌症通过早期发现能根治

- 
三分之一的癌症可通过现有手段延长生命、提高生活质量

从医学本质来说，癌症是正常细胞在遗传、环境、不良生活方式等多重作用下的异常增殖。从细胞变异到形成可察觉的肿瘤，通常需要10年以上——这给了我们足够的“预防窗口期”和“早期干预窗口期”！更重要的是，约80%的癌症发病与后天可控因素相关，每个人都能成为自己健康的第一责任人。

**三级预防：层层筑牢防线**

**一级预防：病因防控，从源头“堵截”癌症**

一级预防是病因防控，核心是减少或消除致癌因素，从源头降低发病风险。以下是5个关键行动：

| 戒烟限酒 | 彻底戒烟，男性每日饮酒≤25g酒精、女性≤15g | 降低22%癌症死亡风险（烟草相关） |

| 健康饮食 | 多吃新鲜蔬果/全谷物，少吃高脂高盐高糖/加工肉 | 降低结直肠癌、胃癌等风险 |

| 规律运动 | 每周150分钟中等强度运动，维持健康体重 | 降低乳腺癌、结直肠癌风险 |

| 接种疫苗 | HPV疫苗（预防宫颈癌）、乙肝疫苗（预防肝癌） | HPV疫苗可降低90%宫颈癌风险 |

| 规避环境风险 | 远离甲醛/苯，做好防晒和职业防护 | 减少环境致癌物暴露风险 |

“我30岁就接种了HPV疫苗，就是想从源头预防宫颈癌。现在每年体检都正常，感觉更安心了！”——28岁女性接种者分享

**二级预防：早诊早治，抓住“治愈黄金期”**

二级预防是早发现、早诊断、早治疗，关键是针对性筛查和警惕异常信号。以下是高危人群筛查指南：

| 肺癌 | 40岁+、吸烟≥20包/年、有肺癌家族史 | 每年胸部低剂量螺旋CT |

| 胃癌/食管癌 | 40岁+、幽门螺杆菌感染、有消化道癌家族史 | 每1-2年胃镜检查 |

| 结直肠癌 | 45岁+、有肠息肉史、炎症性肠病 | 每3-5年结肠镜 |

| 宫颈癌 | 21岁+女性 | 21-29岁每3年TCT，30-65岁每5年TCT+HPV |

| 乳腺癌 | 40岁+女性、有乳腺癌家族史 | 每年乳腺超声/钼靶 |

此外，身体出现这些异常信号要及时就医：

- 
浅表无痛肿块、黑痣突然增大/变色

- 
持续性消化不良、大便带血/习惯改变

- 
痰中带血、声音嘶哑、不明原因体重下降

**三级预防：规范康复，提升生活质量**

三级预防针对癌症患者，核心是通过规范治疗和康复管理，延长生存期、提高生活质量。关键措施包括：

- 
**个体化治疗**

采用多学科诊疗（MDT）模式，整合外科、内科、放疗科等资源，制定手术、靶向治疗等精准方案；

- 
**综合康复**

重视疼痛控制、营养支持和心理疏导，比如通过康复锻炼恢复体力，借助心理咨询缓解焦虑；

- 
**回归社会**

培养健康生活习惯，逐步回归工作和家庭——许多早期患者经过规范治疗后，能像正常人一样生活！

“我爸去年查出早期肺癌，通过MDT团队制定的微创手术方案治疗，现在已经回到工作岗位了。定期复查+规律运动，状态越来越好！”——患者亲属分享

健康人群：坚持戒烟限酒、健康饮食、规律运动，及时接种疫苗；
