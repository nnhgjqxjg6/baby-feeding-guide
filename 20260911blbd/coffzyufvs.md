# 成都西囡医院可以排队做供卵试管吗？

成都西囡妇科医院是成都市能够开展试管技术的医院之一，虽然该医院无法供卵，但是可以供精。而在成都想要做供卵试管，也是可以的，可以去其他能够做供卵试管的医院登记并排队。下面是整理的成都供卵情况，大家可以参考：

- 1. 可做供卵试管的医院：虽然西囡医院不能供卵，但是成都其它试管医院如四川省妇幼保健院、四川大学华西第二医院、成都市妇女儿童中心医院、四川省人民医院、成都市锦江区妇幼保健院以及成都中医药大学附属生殖妇幼医院都可以做供卵试管；
- 2. 供卵相关费用：成都做供卵试管，需要给予者一定的误工、交通和医疗补助，费用在几千到几万不等，而供卵试管因为不涉及促排费用，但有补偿费，所以其实与普通试管费用差不多，大概在3-5万左右；
- 3. 供卵成功率：做供卵试管的卵源质量都是较好的，所以供卵试管成功率也是相对会高一些的，但影响成功率的因素众多，加上选择做供卵试管的医院不同，成功率会有一些差异，总体来说，成都供卵成功率在50%-60%左右；
- 4. 供卵等多久：目前不仅是成都，国内其他城市做供卵试管的卵源都很紧缺，所以等待时间不确定，短则几个月到一年，长则三五年都有可能。
目前成都市共有7家医院可以开展试管婴儿技术，除了成都西囡医院无法供卵，大部分都可以，所以有供卵需求的患者建议前往其他医院去申请。不过需要注意，要带上夫妻双方的结婚证和身份证以及计划生育服务证。
