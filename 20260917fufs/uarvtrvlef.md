# 【必收藏】爱吃鱼的人注意了！这种鱼千万别生吃，赶紧告诉家人！

> 更新时间：2026-09-17 (UTC+8)

央视财经近日播报的一则新闻引发人们对三文鱼的热议，央视财经称 “中国国内市场1/3的三文鱼产自青藏高原” 。

新闻播出后引来不少质疑，有人说央视报道的“淡水三文鱼”实为“虹鳟鱼”，与人们所说的三文鱼并非同一种鱼，并且**生吃虹鳟鱼有害人体健康**。

「
虹鳟别生吃

pinpinlife
」

虹鳟鱼，英文名叫Oncorhynchus mykiss，是大马哈鱼属（太平洋鲑），而大家熟悉的可以刺身生吃的三文鱼是大西洋鲑。虹鳟鱼，只是鱼肉和三文鱼极其相似，但并不属于同一种鱼类。

来源：© 全景网

虹鳟鱼，是在低温淡水环境中生长养殖的，因而被我国的一些商家和养殖基地美称为“淡水三文鱼”。但是，小编需要提醒大家，淡水养殖的虹鳟鱼，**可以吃，但千万别当“三文鱼”生吃！**

来源：© 全景网

淡水鱼、虾通通都是不能生吃的，这是常识！因此，国产虹鳟鱼一样不建议生吃，因为它们的体内可能携带着多种寄生虫，例如阔节裂头绦虫、肺吸虫、华支睾吸虫（俗称肝吸虫）、颚口线虫等等。

以俗名叫肝吸虫的华支睾吸虫为例，有研究显示，在全球肝吸虫感染者中，中国华支睾吸虫感染者所占比例最高，感染人数达1500万。2008年的一份研究显示，肝吸虫在我国广东感染率高达16.42%。

（数据来源： 余一海. 广东顺德2014-2015年华支睾吸虫病流行病学调查. 南方医科大学硕士学位论文. 2016年5月）

来源：© 全景网

「
生吃有讲究

pinpinlife
」

海产的三文鱼最常见的吃法是生吃，生吃不仅味道鲜美，还不会破坏三文鱼的营养价值，但是生吃三文鱼也有很多讲究，做好这几步才能吃到营养又健康的三文鱼。

 / 冷冻杀菌 / 

生吃三文鱼之前一定要杀菌，三文鱼一般采用**低温冷冻的办法进行杀菌**，具体做法是将三文鱼密封好，**放在冰箱里冷冻24小时以上**，这样可以有效杀死三文鱼中的细菌。

 / 忌用水清洗 / 

一块新鲜的三文鱼摆在面前，千万别用水清洗，因为三文鱼长期生活在冰冷的海水里，鱼油含量非常丰富，**越用清水洗油脂会分泌的越多**。

正确的处理方法是：**用厨房吸油纸轻轻吸附三文鱼表面油脂**，即可达到清洗的目的。

 / 切法有讲究 /

购买的三文鱼，一般都是已经经过处理的条形三文鱼块。将三文鱼放置在砧板上，用刀将三文鱼鱼皮去除，用手轻抚去皮的三文鱼竖断面，如果有鱼刺的话可以用镊子或小剪刀将鱼刺轻轻拔出。

余下的三文鱼块要根据不同的部位选择不同刀法，**背部肉质略微坚实，要垂直切下；腹部柔软，刀要倾斜着切入**，在切的过程中应注意一定要一刀切下。

 / 厚度要适中 / 

切片的厚度要适中，一般鱼片**厚度大约为5毫米**，大概就是2个铜板的厚度。这个厚度，吃时既不觉腻，又能感受到肉质的充盈。

 / 蘸酱味更鲜 / 

生吃三文鱼时，搭配酱料吃味道更佳，我们一般选择**青芥末或酱油**。青芥末的辛辣味道有助于**提味、开胃，还能有效杀死三文鱼中的细菌**，而**酱油则能提供咸味、鲜味，调和整体的味道**。

或者是挤点新鲜的**柠檬汁也可以达到提鲜的目的**。

营养功效

 / 促进心血管健康 / 

多吃三文鱼可以**降低患心血管疾病的风险**，对预防心脏病突发、中风、心律失常和高血压等疾病都有一定帮助。

 / 提高认知能力 / 

小孩一定要多吃三文鱼，因为三文鱼中含有能促进大脑发育的物质，对于**提高小孩认知能力****、降低脑部疾病**很有帮助，老人多吃三文鱼还可以**预防老年痴呆。**

 / 让肌肤更年轻 / 

三文鱼中所含的Omega-3可以帮助锁住皮肤细胞中的水分，**促进皮肤生成胶原蛋白和弹性蛋白纤维**，还能淡化肌肤斑点等瑕疵，让皮肤保持年轻状态。

 / 预防癌症 / 

日常适当摄入Omega-3，已被证实有助于预防血癌、多发性骨髓瘤和非霍奇金淋巴瘤等疾病。此外，三文鱼中含有极丰富的维生素D和硒，这两种元素都有利于**预防一些特定种类的癌症**。

 / 盐煎三文鱼 / 

1、把三文鱼清洗干净后，在三文鱼的每一面都撒上海盐，用手涂抹均匀。

2、用保鲜膜将三文鱼盖住，放入冰箱冷藏，腌制5小时然后取出。

3、中火加热平底锅，将腌好的三文鱼放在锅中，用小火干煎，无需放油，先煎有皮的那一面。

4、每一面煎四分钟，煎好后翻面，直到每一面都煎至焦黄，即可出锅。

5、想让味道更鲜，可以剂适量的柠檬汁在肉上，搭配萝卜和米饭一起吃，营养又丰盛，小编忍不住多吃了两碗饭。

 / 三文鱼滑蛋 / 

1、将准备好的三文鱼切成丁放在盘中。

2、取两个鸡蛋，将鸡蛋打碎后搅拌均匀，加入适量的料酒和盐。

3、在锅底倒一层油，然后将三文鱼倒进锅中，用大火翻炒。

4、鱼肉快熟时，把鸡蛋液倒入锅中，和鱼肉一起翻炒，炒熟即可出锅。

5、爽口滑嫩的三文鱼滑蛋就做好了，无论是给大人吃还是小孩吃都非常合适。

 / 红烧三文鱼 / 

**材 料**

****

三文鱼300克 / 水淀粉75ml 

清水240ml / 红糖60克 / 蜂蜜30克

酱油60ml / 辣酱45克 / 蛋黄酱100克

炼乳25克 / 熟白芝麻适量

姜末适量 / 蒜末适量 / 米饭1份

**步 骤 **

****

1、往锅中倒入清水240ml，酱油60ml，红糖60克，蜂蜜30克，葱末姜末若干。

2、开中火加热这些食材，往锅中倒入75ml的水淀粉，搅拌至粘稠。

3、准备300克的三文鱼肉，将熬好的汤汁淋在鱼肉上，盖上保鲜膜，将鱼肉放进冰箱，冷藏腌制2小时。

4、腌好后放入200℃的烤箱内烤制20分钟。

5、蛋黄酱100克，辣酱45克，炼乳25克，搅拌均匀后放入裱花袋中。

6、在烤制好的鱼肉上撒一些白芝麻，将调好的酱汁浇在鱼肉上，一份香喷喷的红烧三文鱼就做好了，和米饭一起吃，吃完还想再来一碗。
