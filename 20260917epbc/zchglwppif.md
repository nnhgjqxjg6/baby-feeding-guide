# 童心启航筑梦未来 妇幼助力健康同行—佳木斯市妇幼保健院组织开展庆祝“六一”儿童节健康宣教主题活动

> 更新时间：2026-09-17 (UTC+8)

**“六一”儿童节快乐**

在“六一”国际儿童节来临之际，为切实聚焦和关爱儿童健康需求，佳木斯市妇幼保健院（佳木斯市儿童医院）精心策划并举办了《2025 童心飞扬・健康启航“六一儿童节”》主题活动。此次活动将健康宣教与趣味互动深度融合，为孩子们打造了一个寓教于乐的健康成长平台，也让家长感受到专业、贴心的医疗服务。佳木斯市妇幼保健院党委书记葛艳华、院长王悦扬等领导班子成员出席活动，现场吸引了约150余组家庭的积极参与。

**亲子互动乐园，畅享欢乐好时光**

活动在托育中心老师热情洋溢的舞蹈中拉开序幕。亲子互动乐园里，创意涂鸦激发孩子无限想象，钓鱼游戏锻炼手眼协调能力，扣扣乐抽奖惊喜连连，感统小游戏让孩子们在亲友的加油声中勇敢挑战自我。此外，托育综合服务中心还推出专属优惠，为 0 - 3 岁宝宝提供免费亲子活动体验一次，托育咨询可享优先抢位名额，将健康礼遇延伸至日常。

**趣味任务闯关，寓教于乐学知识**

活动现场设置了充满童趣的“健康护照”打卡环节。在童趣乐园区，托育中心老师准备了创意涂鸦、趣味钓鱼、扣扣乐抽奖等丰富多样的亲子活动，孩子们在色彩与欢笑中尽情释放创造力；儿童康复中心则设计了感统小游戏，帮助孩子们在挑战中锻炼协调能力。从趣味游戏区到义诊体检区，每完成一项任务，孩子们就能收集一枚奖章，集满3枚奖章即可兑换惊喜礼包。此外，还有以“哪吒”为首的大头娃娃人偶巡游队伍穿梭现场，向孩子们派发气球，将活动氛围推向高潮，让健康知识在欢乐中悄然传递。

**科室联合义诊，健康福利惠民生**

主题活动中，医院的儿科、儿外科、耳鼻喉科、口腔科、儿保科、眼科、儿童康复科、中医儿科和心理科等十大科室专家团队联合坐镇，为孩子们量身定制健康福利；美容科、体检中心也贴心为家长提供关爱服务；眼科开展免费视力检测与验光，守护儿童清晰视界；耳鼻喉科推出 6.1元享原价 160元的耳显微镜常规检查，鼻部和耳部常规检查免费；口腔科提供免费2颗牙齿涂氟、专业口腔检查及口腔设计服务，并通过“给小朋友的一封信”普及护牙知识；儿童康复中心免费进行体态测评与课前评估，儿保科为 3 岁以上儿童免费测量身高体重、绘制生长曲线图、计算肥胖度并给予干预计划，针对 3 周岁以上肥胖、矮小儿童，原价120元的营养体成分分析仅需6.1元。中医儿科推出6.1元 / 次的穴位贴敷体验（原价48元/次），涵盖消食、健脾、止泻等多种功效。同时，美容科为妈妈们提供免费皮肤检测，体检中心推出6.1元骨密度检测（原价90元）、6.1元频谱心电检查（原价 40 元），全方位守护全家健康。

此次 “六一” 儿童节健康宣教活动虽已圆满落幕，但佳木斯市妇幼保健院守护儿童健康成长的脚步永不停歇。未来，医院将持续推出更多长期优惠活动，以专业的医疗技术和温暖的人文关怀，为儿童及家庭的健康保驾护航。
